# 纪念网站交互设计

## 核心交互功能

### 1. 一键编辑系统
- **编辑模式切换**：点击编辑按钮进入/退出编辑模式
- **实时编辑**：直接点击文本区域进行内容修改
- **自动保存**：内容修改后自动保存到本地存储
- **视觉反馈**：编辑状态下显示可编辑区域的视觉提示

### 2. 照片管理功能
- **照片上传**：拖拽或点击上传照片
- **照片展示**：优雅的瀑布流或网格布局展示
- **照片编辑**：为每张照片添加标题、描述和日期
- **分类管理**：按时间或主题分类照片
- **全屏预览**：点击照片可全屏查看

### 3. 回忆记录系统
- **时间轴展示**：按时间顺序展示重要回忆
- **记忆卡片**：每条记忆以卡片形式展示
- **标签分类**：为记忆添加标签便于分类
- **情感表达**：为记忆添加心情和感受

### 4. 互动元素
- **爱心动画**：点击页面任意位置出现飘散的爱心动画
- **音乐播放**：背景音乐控制功能
- **蜡烛点燃**：虚拟蜡烛可以点燃/熄灭
- **留言功能**：访客可以留下温暖的留言

## 用户交互流程

1. **首次访问**：展示欢迎界面，引导用户了解编辑功能
2. **内容管理**：通过编辑模式轻松添加照片和文字
3. **个性化定制**：调整主题色彩和布局风格
4. **分享回忆**：生成专属链接分享给亲友

## 技术实现

- 使用 localStorage 保存所有用户数据
- 支持图片的 base64 编码存储
- 响应式设计适配各种设备
- 优雅的动画过渡效果
